# Security

Please report a security problem in this library, or in the Invoist API, to
**security@invoi.st**, not in a public issue. Include what you found and how
to reproduce it. We answer within two working days and credit you, if you
like, when the fix ships.

Never paste an API key, an access token or a webhook secret into an issue.
If one has leaked, revoke it in Invoist straight away: a business under
Integrations › API, a household under Settings › AI assistants.
